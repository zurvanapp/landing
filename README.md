# صفحهٔ معرفی زروان

صفحهٔ عمومی در `index.html` قرار دارد و بدون build اجرا می‌شود. برای انتشار، همین فایل و کل پوشهٔ `landing-assets` را کنار هم در ریشهٔ وب‌سایت `https://zurvanapp.ir/` قرار دهید.

- Tailwind CSS 4 از jsDelivr CDN و قلم Vazirmatn 33.0.3 از CDN بارگذاری می‌شوند. استایل اختصاصی محلی است تا ساختار و خوانایی صفحه در صورت قطع CDN حفظ شود.
- `dashboard-preview.png` تصویر واقعی نسخهٔ موجود افزونه است.
- `hero-persepolis.png` پس‌زمینهٔ اختصاصی هیرو، ساخته‌شده با ابزار داخلی Image Generation است؛ ستون‌های SVG قبلی از صفحه حذف شده‌اند. تصویر با لایهٔ تیره و محوشدگی تدریجی در پس‌زمینه ادغام می‌شود و در موبایل قاب‌بندی متفاوتی دارد.
- پیش‌نمایش بالای صفحه نمونهٔ معرفی است، نه خود افزونه؛ ساعت و تقویم محلی هستند و آب‌وهوا صریحاً دادهٔ نمونه است.
- انیمیشن‌ها تنظیم `prefers-reduced-motion` را رعایت می‌کنند. صفحه بدون JavaScript هم قابل خواندن است.
- این مخزن شامل صفحهٔ معرفی است؛ لینک‌های دریافت برای مرورگرها پس از انتشار افزونه اضافه می‌شوند.

پیش‌نمایش محلی از ریشهٔ پروژه:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

سپس `http://127.0.0.1:4173/` را باز کنید.
